PRISMA / ALPHA 0.1

Media, in motion.

A small, dependency-free WebGL2 library for images and video. Layer 25 effects, tune their character, and choose how they move.

Get started

Prisma is distributed as native ES modules on GitHub. It is not published to npm yet. Copy the src/ directory into your project, or import from the hosted module below. Pin a Git commit and self-host for a stable production version.

import { createEffect, zoomIn } from
  'https://mmaxence.github.io/prisma/src/index.js';

const fx = createEffect(document.querySelector('.media img'), {
  effect: zoomIn,
  trigger: 'loop',
  duration: 10,
  amount: 0.5
});

Give the source a wrapper with explicit dimensions. Keep meaningful alternative text on the native image.

<div class="media" tabindex="0">
  <img src="photo.jpg" alt="Coastal cliffs at sunset">
</div>
<style>
.media { position: relative; aspect-ratio: 4 / 3; overflow: hidden; }
.media img, .media video {
  display: block; width: 100%; height: 100%; object-fit: cover;
}
</style>

For selective imports, use src/core.js and individual src/effects/zoomIn.js modules. TypeScript declarations are included.

Compose effects

Layers render in order. Each layer transforms the previous result, using a single WebGL context. Reordering changes the look.

import { createEffect, zoomIn, noise } from './src/index.js';

const fx = createEffect(document.querySelector('img'), {
  layers: [
    { effect: zoomIn, amount: 0.5, detail: 0.3 },
    { effect: noise, amount: 0.2, blendMode: 'soft-light' }
  ],
  trigger: 'loop', duration: 10
});

fx.set({ duration: 12 });
// On unmount:
fx.destroy();

Layer options: effect, amount, detail, blendMode, and enabled. An empty layer array displays the original. The playground supports six layers.

Blend modes: normal, multiply, screen, overlay, soft-light, hard-light, difference, exclusion, darken, and lighten. Use normal for camera movements to avoid a double-image blend with the source.

Motion & interaction

Motion is shared across the composition. duration sets one cycle, in seconds.

TriggerBehavior
loopContinuous periodic animation, the default.
hoverActivate on pointer hover or keyboard focus.
clickActivate on click, tap, Enter, or Space. Make the wrapper focusable.
scrollMap the wrapper’s passage through the viewport to progress.
stillFreeze a frame using phase, from 0 to 1.

Practical camera motion

Slow zooms ease in both directions so the loop has no snap. Zoom in and zoom out start in opposite directions. They move the framing; they do not change video playback speed. Vibration plays a short burst between quiet holds. Pan and handheld use a protective crop to hide moving edges. Tilt-shift moves a band of focus with soft blur above and below it.

Start with 10 seconds for zoom, pan, and tilt-shift; 4 seconds for interval vibration. Intensity controls motion or blur strength. The second slider adjusts zoom range, burst length, travel distance, drift character, or focus-band width.

Effect reference

All effects accept images and video, support the five triggers, and preserve the original at zero intensity.

API reference

Controller

set(partialOptions)
Update settings in place, including the layer stack.
pause() / play()
Freeze or resume effect motion. Video playback is independent.
trigger()
Fire a click envelope in click mode.
reset()
Clear a glass impact and reset motion state.
preview(layer) / preview(null)
Temporarily append an effect, then restore the committed composition.
destroy()
Release the canvas, observers, listeners, and GPU objects; restore native media. Safe to call twice.
canvas / stats
The output canvas and diagnostics: frames, cpuMs, width, height, active, fallback, programs, intermediateTextures. CPU submission time is not GPU frame time.

Images & video

Use same-origin media, local uploads, or CORS-enabled remote files. Set crossorigin="anonymous" before a remote source URL, and ensure the source server permits access. YouTube embeds do not expose usable video frames.

<video muted loop playsinline autoplay src="clip.webm"></video>

Play and pause the video through its own API. The playground’s uploads stay in your browser and are never sent to a server. Glass impact creates persistent cracks on an intact image; click again for a new impact or call reset to clear it.

Accessibility & performance

Native media stays in the DOM. Unsupported WebGL2, shader compilation failures, and texture errors reveal the native source and invoke onError. Context restoration rebuilds the renderer.

Reduced-motion preferences freeze shader time. Hidden documents and offscreen effects stop rendering. Static images render on demand; video textures update with decoded frames. The title animations also respect reduced motion and visibility.

The complete media runtime and 25 effect modules are under 12 KB gzip when concatenated, excluding demo assets, fonts, and the demo-only Materia title effects. Each extra layer adds a render pass. Start with a low pixel ratio and a short stack on mobile; tilt-shift uses multiple texture samples.
